## Hi, I'm Sreerag 👋

I build full-stack web apps with **.NET** — clean architecture, solid tests, and real deployments.

### 🚀 Featured project

**[SpendScope](https://github.com/sreeragbuilds/SpendScope)** — *See where every dollar goes.* A personal expense tracker with analytics. · [Live demo](https://spendscope-v9u5.onrender.com)

- ASP.NET Core (.NET 10) API built as vertical feature slices, hosting a Blazor WebAssembly client
- PostgreSQL 16 via EF Core, with per-user data isolation enforced by global query filters
- JWT auth with refresh-token rotation and reuse detection, account lockout, password reset
- Dashboard with spending-by-category and monthly charts, CSV export hardened against formula injection
- Unit, integration, architecture and bUnit component tests; OpenTelemetry tracing; CI on GitHub Actions; deployed on Render
